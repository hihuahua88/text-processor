# Text Processor

A simple Chinese text processing toolkit for learning NLP basics.

## 项目目标
在10天内实现以下功能：
- 中文分词
- 词频统计与停用词过滤
- 关键词提取
- 文本相似度计算（Jaccard + 余弦相似度）

## 文件结构

```
text-processor/
├── README.md          # 项目说明
├── log.md             # 学习日志
├── data/              # 测试文本
├── src/               # 源代码
```
